# Papers

One folder per paper. A folder holds what is needed to build the paper from the notes of `docs/`: the
outline, the list of open points and the sources of the text. The notes themselves stay in `docs/`, where
they are published, and the code and the numbers stay in `scripts/`.

|---|---|---|---|
